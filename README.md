# 📊 Student Performance Prediction System

A machine learning project that predicts students' final examination scores using academic and behavioral factors such as study hours, attendance, previous academic performance, and assignment scores.

## 🎯 Problem Statement

Identifying students who may struggle academically before their final examinations can be difficult. This project uses machine learning regression techniques to predict final exam scores and support early identification of students who may need additional academic assistance.

## 🚀 Objectives

* Predict students' final examination scores.
* Analyze factors affecting academic performance.
* Apply regression-based machine learning algorithms.
* Compare models using RMSE and R².
* Support data-driven academic intervention.

## 🧠 Machine Learning

The project uses supervised machine learning regression techniques.

Models considered:

* Linear Regression
* Decision Tree Regression
* Random Forest Regression

### Evaluation Metrics

**RMSE (Root Mean Square Error)**
Measures the average magnitude of prediction errors.

**R² Score**
Measures how well the model explains variations in the target variable.

## 📌 Features
